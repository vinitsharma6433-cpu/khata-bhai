# Khata Dost by NDS

Digital ledger (khata book) PWA by Nav Durga Sports, Meerut. Record sales, purchases and payments — works offline, data stays on your device (localStorage).

**Live:** https://vinitsharma6433-cpu.github.io/khata-bhai/

## Files
- `index.html` — the full app (single file)
- `manifest.json` — PWA manifest
- `sw.js` — service worker for offline use
